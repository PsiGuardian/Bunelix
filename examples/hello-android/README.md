# Bunelix — Android example

Two independently registered bundles with a dependency, screen registration and an event.

From the repository root, after `npm install` and `npm run build`:

```sh
npm run example:dev
npm run example:build
cd examples/hello-android
npm run android:add
npm run android:sync
npm run android:open
```

An Android SDK and JDK are needed to compile an APK in Android Studio. `android/` is generated by Capacitor and intentionally not included in this repository. No APK is included.
